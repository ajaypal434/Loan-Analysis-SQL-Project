
# Loan Analysis SQL Project

## About the Project

This is a SQL project where I analyzed loan data using MySQL.

I worked on the data to understand loan applications, loan status, loan amount, credit score, loan types, and interest rates.

## What I Analyzed

* Total loan applications
* Approved and rejected loans
* Loan types
* Loan amounts
* Credit score categories
* Loan approval rate
* Customer loan exposure
* Interest rates
* Some risk-related patterns
